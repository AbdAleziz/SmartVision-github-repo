# Smart Vision Studio 👁️

تطبيق سطح مكتب يجمع **13 أداة رؤية ذكية** في شاشة واحدة — بايثون 3.8 + OpenCV، ويعمل على ويندوز 7.

| # | الميزة | الوصف |
|---|--------|-------|
| 1 | كشف الحركة | مقارنة الإطار الحالي بالسابق + لقطة تلقائية |
| 2 | كشف الوجوه | Haar Cascade مع رسم المربعات |
| 3 | التحكم بالماوس باليد | تتبع لون البشرة + معايرة بالنقر + نقرة بإغلاق القبضة |
| 4 | **قراءة QR والباركود (محسّنة)** | عدة أكواد في نفس الإطار، تدوير 90/180/270، تحسين الصورة، قراءة من ملف، نسخ الرابط وفتحه |
| 5 | **عدّاد الأشخاص** | خط عبور تحدده بنقرة، عدّ الدخول/الخروج مع تتبّع متعدد الأشخاص |
| 6 | **التعرف على الوجوه** | تسجيل الأسماء، عرض الاسم فوق الوجه، سجل حضور/انصراف في Excel |
| 7 | **الرسم بالهوا** | تتبّع قلم ملوّن ورسم على الشاشة ثم حفظه صورة |
| 8 | **التحكم بالشرائح** | حركة اليد يميناً/يساراً تقلب الشرائح |
| 9 | **القفل التلقائي** | يقفل ويندوز عند غيابك، ويتعرف عليك عند عودتك |
| 10 | **إشعارات تيليجرام** | صورة عند الحركة أو الوجه الغريب، ورسائل للحضور |
| 11 | **ماسح المستندات** | كشف حواف الورقة، تصحيح الزاوية، تحسين الإضاءة، PDF نظيف متعدد الصفحات |
| 12 | **بوث الصور** | عدّ تنازلي 3-2-1، فلاتر، إطار زخرفي، تمويه الوجه للخصوصية |
| 13 | **لوحة الإحصائيات** | حركات اليوم، أكثر ساعة نشاطاً، رسم بياني، آخر 7 أيام |

إضافة إلى **ثيم فاتح/غامق** و**واجهة عربية/إنجليزية** بزر واحد.

## التثبيت

```bat
:: Python 3.8 (آخر نسخة تدعم ويندوز 7)
pip install -r requirements.txt
python smart_vision.py
```

### التبعيات الأساسية
| الحزمة | لماذا | إلزامي؟ |
|--------|-------|---------|
| `numpy==1.21.6` | حساب الصور | ✅ |
| `opencv-contrib-python==4.5.5.64` | كل الرؤية + LBPH للتعرف على الوجوه | ✅ |
| `pyautogui==0.9.53` | التحكم بالماوس ولوحة المفاتيح | ✅ |
| `pyzbar==0.1.9` | الباركود الخطي (QR يعمل بدونه) | اختياري |
| `Pillow>=8.0` | معاينة الصور المصغّرة (بدونها تعمل كل الوظائف) | اختياري |
| `openpyxl>=3.0` | تصدير Excel الحقيقي | اختياري |
| `SpeechRecognition` + `PyAudio` | الأوامر الصوتية (بدونها نفتح الإدخال الصوتي في ويندوز) | اختياري |

> بدون `opencv-contrib` يعمل التعرف على الوجوه **بالوضع البديل** (وصف إحصائي 32×32) — أضعف دقة لكنه لا يتعطّل.

## طريقة الاستخدام

### النمط�� (الشريط الجانبي)
اضغط رقم النمط أو اسمه:

| النمط | ماذا يفعل |
|-------|-----------|
| 1 كشف الحركة | تنبيه + لقطة عند الحركة |
| 2 كشف الوجوه | مربعات حمراء على كل وجه |
| 3 التحكم بالماوس | انقر على يدك في الفيديو لمعايرة اللون |
| 4 QR / باركود | يقرأ عدة أكواد ويعرض النص |
| 5 عدّاد الأشخاص | انقر نقرتين داخل الفيديو لتحديد خط العبور |
| 6 التعرف على الوجوه | يعرض الأسماء فوق الوجوه ويسجّل الحضور |
| 7 الرسم بالهوا | وجّه قلماً ملوّناً للرسم |
| 8 التحكم بالشرائح | حرّك يدك يميناً ويساراً |
| 9 إشارة اليد للصوت | ارفع يدك لبدء الإدخال الصوتي |
| 10 النمط الشامل | حركة + وجوه + أكواد معاً |

### التبويبات
- **المعاهدة**: الفيديو، حالة النظام، الأكواد المقروءة، السجل.
- **العدّاد**: أرقام الدخول/الخروج وسجل الأحداث.
- **التعرف على الوجوه**: تسجيلFaces جديدة + جدول الحضور + تصدير CSV/Excel.
- **الماسح**: التقاط وتصحيح الورق ثم حفظ PDF.
- **بوث الصور**: الفلاتر والإطار والتمويه ثم الالتقاط.
- **الإحصائيات**: بطاقات اليوم + رسم بياني 24 ساعة + آخر أسبوع.
- **الرسم**: مسح/حفظ الرسمة.
- **الإعدادات**: تيليجرام، القفل التلقائي، الصوت، المجلدات.

### تيليجرام
1. افتح [@BotFather](https://t.me/BotFather) وأنشئ بوتاً وخذ الـ **Token**.
2. أرسل رسالة لـ [@userinfobot](https://t.me/userinfobot) لمعرفة **Chat ID**.
3. من تبويب الإعدادات: فعّل + الصق القيم + «إرسال رسالة اختبار».
4. فعّل ما تريد إشعاره (حركة / وجه غريب / حضور).

### القفل التلقائي
- فعّل «القفل عند غيابك» وحدد الثواني.
- **«افتح فقط للوجه المسجّل»**: الوجه المجهول لا يُبقي الجهاز مفتوحاً.
- عند رجوعك يتعرف عليك البرنامج ويُشغّل الإدخال الصوتي/إشعار تيليجرام.
- **الفتح التلقائي للويندوز** اختياري وخطِر: ينقر كلمة المرور عبر `pyautogui` (قد تفشل مع شاشة الأمان في ويندوز 10/11). الوضع الافتراضي «إشعار فقط».

### سجل الحضور
يُحفظ في `data/attendance/attendance_YYYY-MM-DD.csv` (يفتح مباشرة في Excel بالعربية)
ويمكن تصديره `.xlsx` حقيقي من التبويب.

## الاختبارات

```bat
python tools\lint.py        :: فحص الأسماء غير المعرّفة في كل الملفات (AST)
python tools\selftest.py    :: 117 اختبار (ترجمة، إعدادات، عدّاد، حضور، PDF، قفل، تيليجرام...)
python tools\uitest.py      :: 35 دخانة اختبار للواجهة (بناء النافذة، تبديل اللغة/الثيم، الأحداث)
```

الاختبارات لا تحتاج OpenCV ولا Tkinter (يستخدم `tools/stubs` بديلاً بسيطاً)،
وتعمل كما هي على GitHub Actions قبل بناء الـ EXE.

> `tools/uitest.py` ينسخ المشروع إلى مجلد مؤقت قبل التشغيل حتى لا يلوّث
> مجلد التطبيق بـ `settings.json` ومجلد `data`.
